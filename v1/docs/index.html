はじめに

「カリキュラム備考欄チェックシステム (Curriculum Analyzer)」は、MSLを組み込みブラウザで確認しながら蓄積し、記載内容の整合性を自動精査して Excel / CSV を出力する Windows デスクトップアプリケーションです。

カリキュラム備考欄の点検作業において、手動での目視確認やコピペの手間を大幅に削減し、必須項目の漏れや記述ミスを瞬時に発見できます。

💡 本ツールの主な特徴
  • 直感的な画面収集：専用組み込みブラウザで対象ページを表示し、F9 キーを押すだけで瞬時に抽出・蓄積。
  • 自動精査エンジン：予定・目標・宿題・連絡事項などの必須セクション漏れや文字数をバックグラウンドで高速判定。
  • Excel / CSV 同時出力：集計結果は日付・教室名付きの Excelブック（.xlsx）と BOM付きUTF-8 CSV（.csv）として自動生成。
  • 完全ローカル処理：生徒データや備考欄本文はPC内部のみで処理され、外部通信は一切行いません。

動作環境

本ソフトウェアは、Python等の追加インストールを必要としない単一実行ファイル（Onefile EXE）として提供されます。

項目 要件・仕様
対応 OS Windows 10 (バージョン 1809 以降) / Windows 11 (64-bit)
アーキテクチャ x86-64 / AMD64 (64-bit) ※ARM64版・32bit版Windowsは非対応
ファイルシステム NTFS（PCのローカルディスク Cドライブ等での実行を推奨）
ランタイム 不要（動作に必要なコンポーネントはすべてEXE内に内包）
⚠️ ご注意

ネットワークドライブやクラウド同期フォルダ（OneDrive、Google Drive、Dropbox等）上で直接実行すると、データベースのロック競合やキャッシュ保存エラーの原因となります。必ずローカルディスク（例: C:\Tools\Curriculum_Analyzer 等）に展開してご利用ください。

インストール・準備

インストーラーの実行やレジストリ登録は不要です。配布されたZIPファイルを展開するだけですぐに使用できます。

  1. ZIPファイルの解凍
    ダウンロードした Curriculum_Analyzer_v1.0.0.zip を右クリックし、「すべて展開」を選択してローカルディスクの任意のフォルダに解凍します。
  2. 実行ファイルの確認
    展開されたフォルダ内に Curriculum_Analyzer.exe があることを確認します。
  3. アプリケーションの起動
    Curriculum_Analyzer.exe をダブルクリックして起動します。

初回起動時に自動生成されるファイル・フォルダ

初回起動時、EXEと同じ階層に以下のファイルやフォルダが自動的に作成されます：

  • config.ini：初期URLや拡大率を管理する設定ファイル（未存在時に自動作成）
  • user_data/：ブラウザのログインセッション・Cookieを安全に保存するフォルダ
  • error.log：動作エラー発生時の診断ログファイル
🛡️ 多重起動防止機能

本アプリは多重起動を自動検知します。既に起動している状態で再度EXEをクリックした場合は、既存のウィンドウが自動的に最前面へ復帰し、新規プロセスは安全に終了します。

基本的な使い方

日常の精査業務は、以下の 4つのステップ でシンプルに完了します。

ステップ 1: ログイン・画面表示

  1. アプリケーションを起動すると、組み込みブラウザに対象のWebシステムが表示されます。
  2. 通常のブラウザと同様にログインID・パスワードを入力してログインしてください。
  3. ログイン情報やセッションCookieは user_data フォルダに安全に保持されるため、次回起動時以降は再ログインを省略できます。
🌐
【ステップ1：画面表示】
組み込みブラウザで対象のカリキュラム画面を開きます
組み込みブラウザでのカリキュラム画面表示

ステップ 2: データの読み取り・蓄積 (F9)

  1. カリキュラムのテーブルが表示されているページを表示します。
  2. キーボードの F9 キーを押すか、ツールバーの 「このページを読み取る (F9)」 ボタンをクリックします。
  3. 画面上のテーブルから、学籍番号・生徒氏名・学年・受講区分・科目・カリキュラム備考欄本文が自動的に抽出され、内部に蓄積されます。
  4. ウィンドウ上部のタイトルバーに現在の累計件数（例: [蓄積: 45件]）が更新されます。
  5. 複数ページの連続蓄積：対象画面に次ページがある場合は、画面操作で次ページへ進み、同様に F9 を押すことで順次データを追加蓄積できます。
⚡
【ステップ2：データ読み取り・蓄積】
F9キーを押すとトースト通知とともに累計件数が増加します
F9キー押下によるデータ蓄積（件数がリアルタイム更新）

ステップ 3: 直前読み取りの取り消し (Ctrl + Z)

  1. 誤って関係のないページで F9 を押してしまった場合や、重複して読み取ってしまった場合は、キーボードの Ctrl + Z を押すか、ツールバーの 「↶ 1つ戻す」 ボタンをクリックします。
  2. 直前の F9 読み込みバッチ単位でデータが取り消され、蓄積前の状態に安全に戻ります（最大30回まで遡及可能）。

ステップ 4: 集計・Excel/CSV出力 (Ctrl + Enter)

  1. 必要な全ページ（または全生徒分）の読み取りが完了したら、キーボードの Ctrl + Enter を押すか、ツールバーの 「集計してExcel出力」 ボタンをクリックします。
  2. 確認ダイアログが表示されるので「はい」を選択すると、内部判定エンジンが起動し、全件の整合性・必須項目チェックを高速に実行します。
  3. 集計が完了すると、ユーザーの「ダウンロード」フォルダ（Downloads） 内に以下の2つのファイルが自動保存されます：
    • Excelファイル（.xlsx）：精査判定結果・エラー詳細・見やすいセル書式付き
    • CSVファイル（.csv）：Excelで文字化けしないBOM付きUTF-8形式（固定15列）
  4. 出力完了と同時に、Windows Explorer が自動的に起動し、保存されたファイルが選択状態でハイライト表示されます。

精査・判定ルールについて

集計実行時、内部の判定エンジンがカリキュラム備考欄本文（raw_instruction）を解析し、以下の基準で自動判定を行います。

重要度（判定） 主なチェック内容 解説・対処方法
CRITICAL / ERROR
（重大な不備・エラー）		 ・必須セクションの完全欠落
・学籍番号や氏名の未取得
・備考欄本文が空または極端に短い 		授業運営上不可欠な記載（次回予定・単元目標など）が抜けている状態です。出力されたExcelの該当セルが赤色でハイライトされます。
WARNING / REVIEW
（警告・要確認）		 ・推奨セクション（宿題・連絡事項等）の漏れ
・規定文字数未満の記述
・書式揺れ・定型句の不足 		記載内容に不足や確認を要する点があります。出力されたExcelで黄色でハイライトされます。
PASS
（正常）		 ・全必須セクション網羅
・十分な文字数と書式準拠		 精査基準を満たしており、問題ありません。

設定ファイル (config.ini) と通信環境

アプリケーションの初期動作は、EXEと同階層にある config.ini で簡単にカスタマイズ可能です。メモ帳等のテキストエディタで編集できます。

[General]
base_url = https://your-school-portal.example.com/curriculum
ignore_ssl_errors = false

[Display]
zoom_factor = 1.0
設定項目 標準値 解説・設定のポイント
base_url （空または指定URL） 起動時およびツールバーの「ホーム」ボタン押下時に開くURLを指定します。未設定の場合は初回起動時に入力ダイアログが開きます。
ignore_ssl_errors false SSL/TLS証明書のエラーを無視するか設定します（true / false）。通常はセキュリティ保護のため false のままにしてください。
zoom_factor 1.0 起動時の初期画面拡大率を指定します（0.5 〜 2.0）。画面文字が小さくて見えにくい場合は 1.2 等に調整してください。

社内プロキシ・VPN環境での注意点

🌐 社内ネットワーク接続時の確認
  • VPN接続：拠点外からアクセスする場合、指定の社内VPNに接続していることを確認してください。VPN切断時はログイン画面やテーブルが表示されない場合があります。
  • 証明書エラー画面が出る場合：社内プロキシによるSSLインスペクションを行っている環境で証明書警告が表示されて進めない場合は、管理者に相談のうえ ignore_ssl_errors = true に設定してください。

よくある質問とトラブルシューティング (FAQ)

出力されたファイルはどこに保存されますか？
集計された Excel ファイル（.xlsx）および CSV ファイル（.csv）は、すべてお使いのPCの 「ダウンロード」フォルダー（C:\Users\<ユーザー名>\Downloads） に自動保存されます。
集計が完了すると同時に Windows Explorer が開き、生成されたファイルが自動選択されますので、探す手間なくすぐに開くことができます。
画面が真っ白なまま表示が進みません
以下の項目を順にご確認ください：
  1. config.ini の base_url に正しいWebサイトのURLが入力されているか確認してください。
  2. 社内LANや指定のVPN接続が有効になっているかご確認ください。
  3. キーボードの F5 を押して画面を再読み込みしてください。
F9キーを押しても「有効なデータがありません」と表示されます
Webサイト側のJavaScript描画が完了する前に F9 を押すと、テーブル構造を検出できない場合があります。画面上のカリキュラムテーブルが完全に表示されるまで数秒待ってから、再度 F9 を押してください。
誤ってアプリを閉じてしまいました。蓄積データは消えてしまいますか？
ご安心ください。セッション自動復元機能が搭載されています。
読み取り中のデータはリアルタイムに自動退避されています。再度アプリを起動すると「前回の未集計データ（〇件）が見つかりました。復元しますか？」と確認ダイアログが表示されますので、「はい」を選択することで直前の作業状態へ即座に復帰できます。
エラーが発生して動かなくなってしまった場合は？
予期せぬ例外が発生した場合は、Curriculum_Analyzer.exe と同じフォルダ内にある error.log に詳細なログが出力されます。社内システム管理者や開発担当へ問い合わせる際は、この error.log ファイルを添付してください。

セキュリティと個人情報の保護

教育機関・学習教室で扱われる生徒情報および指導記録の機密性を守るため、以下の厳格なプライバシー設計を採用しています。

  • 完全ローカル完結処理
    抽出された学籍番号・生徒氏名・指導内容・判定結果は、すべて利用者のパソコン内部でのみ処理されます。外部サーバーへの送信、クラウド同期、テレメトリ収集、AI検索API等への送信は一切行われません。
  • 一時キャッシュの完全自動消去
    蓄積作業中の一時キャッシュデータは、Excel / CSV の出力が正常に完了した瞬間にディスク上から自動的に完全削除されます。
  • ログイン情報の保護
    ブラウザセッションやCookieはローカルの user_data フォルダ内に保護され、第三者へ送信されることはありません。
