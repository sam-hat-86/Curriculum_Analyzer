Core Capabilities

教室運営の課題をテクノロジーで解決

教育現場の実務フローに寄り添い、点検の手間を極限まで削減する先進機能を搭載。

🏫

複数教室・全ページの完全自動巡回

対象教室の一覧画面から全生徒・科目の詳細カリキュラムを自動収集。最終ページまでの自動ページネーションに加え、別教室への連続巡回もワンクリックで完了します。

自動ページ送り 複数教室ループ デモ生徒自動除外
📊

要対応ダッシュボード付き Excel 出力

「集計結果」シートで進捗遅れや指導案不備を俯瞰把握。進捗率・単元詳細・備考欄精査・サマリーの用途別 5 シートをワンクリック出力。

要対応ダッシュボード 5シート構成
🔍

コピペ・類似文章の高速自動検知

生徒間・科目間で酷似した備考欄や指導案の使い回しを瞬時に抽出。形骸化した指導案の是正と指導品質の向上を力強くサポートします。

文章類似度分析 不備即時フラグ
🛡️

外部送信ゼロ・安心の完全ローカル設計

収集した生徒名・学籍番号・指導内容はすべて利用者の PC 内部（ローカル SQLite）のみで処理。外部サーバーへの送信やテレメトリ通信は一切行いません。

スタンドアロン動作 ローカル暗号化DB 中間自動保存
