================================================================================
授業指示書・カリキュラム 精査ブラウザ (Curriculum Analyzer) - 取扱説明書
================================================================================

本ソフトウェアをご利用いただきありがとうございます。
本書は、「授業指示書・カリキュラム 精査ブラウザ」の導入手順、基本操作、設定、
および保守に関する説明書です。ご使用前に必ずご一読ください。


--------------------------------------------------------------------------------
1. 対応OS・動作環境
--------------------------------------------------------------------------------
- 対応OS: Windows 10 (バージョン 1809 以降) / Windows 11
- アーキテクチャ: 64-bit (x86-64 / AMD64)
- ファイルシステム: NTFS (ローカルディスク)

※ Windows Server、ARM64版Windows、macOS、Linux等は非対応です。
※ ネットワークドライブ、USBメモリ、クラウド同期フォルダ(OneDrive等)上での
   直接実行は動作保証外となります。必ずローカルディスクへ展開してご使用ください。


--------------------------------------------------------------------------------
2. 導入方法 (インストール)
--------------------------------------------------------------------------------
本ソフトウェアはインストール作業（インストーラーの実行）を必要としません。

1. 配布されたZIPファイル（Curriculum_Analyzer_vX.Y.Z.zip）を、ローカルディスク
   （例: C:\Tools\Curriculum_Analyzer 等）の任意のフォルダへ展開（解凍）します。
2. 展開されたフォルダ内に「Curriculum_Analyzer.exe」が存在することを確認してください。


--------------------------------------------------------------------------------
3. 起動方法
--------------------------------------------------------------------------------
1. 展開先フォルダ内の「Curriculum_Analyzer.exe」をダブルクリックして起動します。
2. 初回起動時、同フォルダ内に以下のファイル・フォルダが自動的に生成されます。
   - config.ini : 設定ファイル（未存在時）
   - user_data/ : ブラウザのセッション情報・Cookie・キャッシュ保存フォルダ
   - error.log  : ログ出力ファイル
3. 多重起動防止機能が組み込まれているため、既に起動中の場合は既存のウィンドウが
   前面に表示され、新しいプロセスは自動的に終了します。


--------------------------------------------------------------------------------
4. 設定ファイル (config.ini) と base_url
--------------------------------------------------------------------------------
アプリケーションの動作設定は、同階層の「config.ini」で管理されます。
メモ帳等のテキストエディタで編集可能です。

【設定例】
[General]
base_url = https://example.com/curriculum
ignore_ssl_errors = false

[Display]
zoom_factor = 1.0

【各項目の説明】
- base_url :
  起動時およびツールバーの「ホーム」ボタン押下時に開くURLを指定します。
  使用可能なスキームは http://, https://, file:/// です。
- ignore_ssl_errors :
  SSL/TLS証明書エラーを無視するかどうかを設定します (true / false)。
  通常はセキュリティ保護のため false を指定してください。
- zoom_factor :
  ブラウザ画面の初期拡大率を指定します (0.5 ～ 2.0)。標準は 1.0 です。


--------------------------------------------------------------------------------
5. 基本操作フロー
--------------------------------------------------------------------------------
【手順 1: ログイン】
1. アプリケーション起動後、組み込みブラウザに対象Webサイトが表示されます。
2. 画面上の入力欄から通常のブラウザと同様にログインを行ってください。
3. ログイン情報やセッションCookieは「user_data」フォルダに安全に永続化されるため、
   次回以降は再ログインの手間を省くことができます。

【手順 2: 画面のデータ読み込み (F9キー)】
1. ブラウザを操作し、授業指示書やカリキュラムのテーブルが表示されているページへ
   移動します。
2. キーボードの「F9」キーを押すか、ツールバーの「データ読み込み (F9)」ボタンを
   クリックします。
3. 画面上のテーブルから「学籍番号」「受講区分」「科目」「指示書本文」が自動的に
   抽出され、内部リポジトリへ蓄積されます。
4. 読み込み成功後、画面変化監視モード（5秒間）に入り、画面上の操作や別ページへの
   遷移を検知すると再び準備完了（READY）状態に戻ります。
5. 複数ページにまたがるデータがある場合は、手動で次ページへ移動し、同様に「F9」を
   押して順次読み込みを繰り返してください。

【手順 3: 読み込みの取り消し (Undo: Ctrl+Z)】
1. 誤ったページを読み込んでしまった場合は、キーボードの「Ctrl+Z」キーを押すか、
   ツールバーの「取り消し」ボタンをクリックします。
2. 直前のF9読み込みバッチ単位でデータが取り消されます（最大30世代まで遡及可能）。

【手順 4: 集計・CSV出力 (F10キー)】
1. 必要な全ページの読み込みが完了したら、キーボードの「F10」キーを押すか、
   ツールバーの「集計実行 (F10)」ボタンをクリックします。
2. 内部の判定エンジンが指示書本文の精査（予定・目標・連絡事項等の記述確認、
   文字数判定など）をバックグラウンドで高速に実行します。
3. 精査結果が BOM付きUTF-8形式の固定15列CSVファイルとして出力されます。
   （Excel等でそのまま文字化けなく開くことができます）
4. 出力完了後、Windows Explorer が自動的に起動し、出力されたCSVファイルが
   選択された状態で表示されます。


--------------------------------------------------------------------------------
6. キャッシュ (cache) とデータ保持・個人情報の取り扱い
--------------------------------------------------------------------------------
- 未集計データの一時退避:
  F9キーで読み込んだデータは、停電や不意の強制終了から保護するため、同階層の
  「_session_cache.jsonl」へリアルタイムに一時保存されます。
- キャッシュからの復元:
  万が一アプリケーションが異常終了した場合、次回起動時に前回の未集計データを
  復元するかどうかを確認するダイアログが表示されます。
- キャッシュの自動削除:
  CSV出力（F10）が正常に完了した時点で、一時キャッシュファイルは自動的に
  安全に削除されます。
- 個人情報の保持:
  一時キャッシュやuser_dataフォルダには、学籍番号や受講情報が含まれます。
  共用のPC環境で使用する場合は、作業完了後にCSVファイルを安全なストレージへ移動し、
  必要に応じて「user_data」フォルダを削除してください。


--------------------------------------------------------------------------------
7. 更新方法 (アップデート手順)
--------------------------------------------------------------------------------
本ソフトウェアには自動アップデート機能はありません。新しいバージョンへの更新は
以下の手順で手動にて実施してください。

1. GitHub Release より最新版のZIPアーカイブをダウンロードします。
2. 新しいフォルダにZIPアーカイブを展開します。
3. 以前使用していた旧バージョンのフォルダから、以下のファイル・フォルダを
   新しいフォルダへコピー（上書き）します。
   - config.ini
   - user_data/ （ログイン状態・セッション情報を引き継ぐ場合）
4. 新しいフォルダ内の「Curriculum_Analyzer.exe」を起動します。
