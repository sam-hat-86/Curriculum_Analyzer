# 授業指示書・カリキュラム 精査ブラウザ (Curriculum Analyzer)

Web上の授業指示書およびカリキュラム画面を組み込みブラウザで手動操作しながら収集し、指示書の整合性を精査してCSVファイルを出力するWindowsデスクトップアプリケーションです。

---

## 1. ソフトウェア概要

「授業指示書・カリキュラム 精査ブラウザ」は、教育機関や学習現場における授業指示書・カリキュラム情報の精査作業を支援するために開発されました。

ユーザーが組み込みブラウザ上で対象ページへ手動遷移・ログインし、画面上に表示されたカリキュラムテーブルから以下の項目を安全に抽出・蓄積します。

- **学籍番号** (`student_id`)
- **生徒氏名** (`student_name`)
- **学年** (`grade`)
- **受講区分** (`division`)
- **科目** (`subject`)
- **指示書本文** (`raw_instruction`)

蓄積された指示書データは、内部の判定エンジンによって自動精査され、必須セクションの漏れや不整合などのエラー（ERROR）および警告（WARNING）を検出します。最終結果は、Excel等で直接開くことができる **BOM付きUTF-8（固定15列）CSV** として出力されます。

---

## 2. 対応OS・動作環境

- **対応OS**: Windows 10 (バージョン 1809 以降) / Windows 11
- **アーキテクチャ**: 64-bit (x86-64 / AMD64)
- **ファイルシステム**: NTFS（ローカルディスク上での実行を推奨）
- **ランタイム**: 単一実行可能ファイル（Onefile EXE）として配布されるため、Python等の事前インストールは不要です。

> **注意**: Windows Server、ARM64版Windows、macOS、Linux環境はサポート対象外です。また、ネットワークドライブやクラウド同期フォルダ（OneDrive等）上での直接実行は動作保証外となります。必ずローカルディスクへ展開してご使用ください。

## 3. 導入・起動方法

本ソフトウェアはインストーラーの実行を必要としません。

### 導入手順
1. 配布されたZIPファイル（`Curriculum_Analyzer_vX.Y.Z.zip`）を、ローカルディスク（例: `C:\Tools\Curriculum_Analyzer` 等）の任意のフォルダへ展開（解凍）します。
2. 展開されたフォルダ内に `Curriculum_Analyzer.exe` が存在することを確認してください。

### 起動フロー
1. 展開先フォルダ内の `Curriculum_Analyzer.exe` をダブルクリックして起動します。
2. 初回起動時、同フォルダ内に以下のファイル・フォルダが自動的に生成されます：
   - `config.ini`: アプリケーション設定ファイル（未存在時）
   - `user_data/`: ブラウザのセッション情報・Cookie・キャッシュ保存フォルダ
   - `error.log`: ログ出力ファイル
3. **多重起動防止機能**: 既に起動中の場合は既存のウィンドウが最前面に表示され、新しいプロセスは自動的に終了します。

## 4. 設定ファイル (config.ini) と base_url

アプリケーションの動作設定は、EXEと同階層の `config.ini` で管理されます。メモ帳等のテキストエディタで編集可能です。

```ini
[General]
base_url = https://example.com/curriculum
ignore_ssl_errors = false

[Display]
zoom_factor = 1.0
```

### 設定項目一覧
- **`base_url`**:
  - 起動時およびツールバーの「ホーム」ボタン押下時に開くURLを指定します。
  - 使用可能なスキーム: `http://`, `https://`, `file:///`
  - 初回起動時に未設定の場合は、起動時に接続先URLの入力ダイアログが表示されます。
- **`ignore_ssl_errors`**:
  - SSL/TLS証明書エラーを無視するかどうかを設定します (`true` / `false`)。
  - 通常はセキュリティ保護のため `false` を指定してください。
- **`zoom_factor`**:
  - ブラウザ画面の初期拡大率を指定します (`0.5` ～ `2.0`、標準: `1.0`)。

## 5. 基本操作フロー

### 【手順 1: ログイン】
1. アプリケーション起動後、組み込みブラウザに対象Webサイトが表示されます。
2. 画面上の入力欄から通常のブラウザと同様にログインを行ってください。
3. ログイン情報やセッションCookieは `user_data` フォルダに安全に永続化されるため、次回以降は再ログインの手間を省くことができます。

### 【手順 2: 画面のデータ読み込み (F9キー)】
1. ブラウザを操作し、授業指示書やカリキュラムのテーブルが表示されているページへ移動します。
2. キーボードの **F9キー** を押すか、ツールバーの「データ読み込み (F9)」ボタンをクリックします。
3. 画面上のテーブルから必要項目が自動的に抽出され、内部リポジトリへ蓄積されます。
4. 読み込み成功後、画面変化監視モード（5秒間）に入り、画面上の操作や別ページへの遷移を検知すると再び準備完了（READY）状態に戻ります。
5. 複数ページにまたがるデータがある場合は、手動で次ページへ移動し、同様に **F9** を押して順次読み込みを繰り返してください。

### 【手順 3: 読み込みの取り消し (Undo: Ctrl+Z)】
1. 誤ったページを読み込んでしまった場合は、キーボードの **Ctrl+Z** を押すか、ツールバーの「取り消し」ボタンをクリックします。
2. 直前のF9読み込みバッチ単位でデータが取り消されます（最大30世代まで遡及可能）。

### 【手順 4: 集計・CSV出力 (F10キー)】
1. 必要な全ページの読み込みが完了したら、キーボードの **F10キー** を押すか、ツールバーの「集計実行 (F10)」ボタンをクリックします。
2. 内部の判定エンジンが指示書本文の精査（予定・目標・連絡事項等の記述確認、文字数判定など）をバックグラウンドで高速に実行します。
3. 精査結果が **BOM付きUTF-8形式の固定15列CSVファイル** として出力されます。
4. 出力完了後、Windows Explorer が自動起動し、生成されたCSVファイルを選択状態で表示します。

## 6. 注意事項・トラブルシューティング

- **画面が真っ白のまま進まない場合**:
  - `config.ini` の `base_url` に正しいURLが設定されているか確認してください。
  - 社内ネットワークやプロキシ、VPN接続の状態を確認してください。
- **F9キーを押しても読み込まれない場合**:
  - カリキュラムのテーブルが完全に描画されるまで数秒待ってから再試行してください。
  - Webサイト側の仕様変更等でテーブル構造が変わった場合、`selectors.json` のセレクタ設定を調整することでコード修正なしに対応可能です。
- **誤ってアプリを終了してしまった場合（セッション復元）**:
  - 読み込み中のデータは `_session_cache.jsonl` に自動退避されています。
  - 次回起動時に「前回の未集計データ（X件）が見つかりました。復元しますか？」と表示されるため、「はい」を選択すると直前の状態へ復帰できます。
- **エラーログの確認**:
  - 予期せぬ動作が発生した場合は、同フォルダ内の `error.log` を確認してください。直近の例外スタックトレースが記録されています。

## 7. 公開データおよび個人情報の取り扱い

- **ローカル完結処理**: 抽出された生徒データ（学籍番号、氏名等）や指示書本文は、すべて利用者のローカル端末内でのみ処理されます。外部サーバーへの送信、テレメトリ収集、Web検索等は一切行いません。
- **公開リポジトリへの個人情報排除**: 本リポジトリのソースコード、コミット履歴、テスト用フィクスチャ、モックHTML、ドキュメント画像には、実在する個人情報（学籍番号、氏名等）や認証情報は一切含まれていません。
- **キャッシュのライフサイクル**: 読み込み中の一時キャッシュ（`_session_cache.jsonl`）は、CSV出力が正常完了した時点で自動的に完全削除されます。

脆弱性の報告やセキュリティ方針については [SECURITY.md](SECURITY.md) をご確認ください。
