# 授業指示書・カリキュラム 精査ブラウザ (Curriculum Analyzer)

Web上の授業指示書およびカリキュラム画面を組み込みブラウザで手動操作しながら収集し、指示書の整合性を精査してCSVファイルを出力するWindowsデスクトップアプリケーションです。

---

## 1. ソフトウェア概要

「授業指示書・カリキュラム 精査ブラウザ」は、教育機関や学習現場における授業指示書・カリキュラム情報の精査作業を支援するために開発されました。

ユーザーが組み込みブラウザ上で対象ページへ手動遷移・ログインし、画面上に表示されたカリキュラムテーブルから以下の4項目を安全に抽出・蓄積します。

1. **学籍番号** (`student_id`)
2. **受講区分** (`division`)
3. **科目** (`subject`)
4. **指示書本文** (`raw_instruction`)

蓄積された指示書データは、内部の判定エンジンによって自動精査され、必須セクションの漏れや不整合などのエラー（ERROR）および警告（WARNING）を検出します。最終結果は、Excel等で直接開くことができる **BOM付きUTF-8（固定15列）CSV** として出力されます。

---

## 2. 対応OS・動作環境

- **対応OS**: Windows 10 (バージョン 1809 以降) / Windows 11
- **アーキテクチャ**: 64-bit (x86-64 / AMD64)
- **ファイルシステム**: NTFS（ローカルディスク上での実行を推奨）
- **ランタイム**: 単一実行可能ファイル（Onefile EXE）として配布されるため、Python等の事前インストールは不要です。

> **注意**: Windows Server、ARM64版Windows、macOS、Linux環境はサポート対象外です。また、ネットワークドライブやクラウド同期フォルダ（OneDrive等）上での直接実行は非推奨です。

---

## 3. 主要機能

- **組み込みChromiumブラウザ**:
  - `PyQt6-WebEngine` による安全で高速なWeb表示。
  - セッション情報（Cookie、LocalStorage）の永続化により、次回起動時もログイン状態を維持。
- **直感的なデータ読み込み**:
  - カリキュラム画面で **F9キー** を押すだけで、現在表示中のテーブルデータを一括読み込み。
  - 複雑なHTML構造や複数テーブルから最適なテーブルを自動スコアリング判別。
- **安全な取り消し (Undo)**:
  - 誤って読み込んだ場合でも、**Ctrl+Z** で直近の読み込みバッチを最大30世代まで取り消し可能。
- **セッションキャッシュ保護**:
  - 未集計データはローカルの一時キャッシュ（`_session_cache.jsonl`）に自動退避。
  - アプリケーションが不意に終了した場合でも、次回起動時にキャッシュからの復元を確認。
- **指示書判定エンジン**:
  - 【予定】【目標】【連絡事項】等のセクション構造、文字数閾値、定型文の有無などを純粋ロジックで高速精査。
- **BOM付きUTF-8 CSV出力 & Explorer連携**:
  - **F10キー** または集計ボタンで精査結果を固定15列のCSVへエクスポート。
  - CSV出力完了後、Windows Explorerを自動起動して生成先ファイルを選択表示。

## 5. 公開データおよび個人情報の取り扱い

本リポジトリおよび公開版ソフトウェアにおいて、プライバシー保護とセキュリティの観点から以下の運用を徹底しています。

- **ローカル完結処理**: 抽出された生徒データ（学籍番号等）や指示書本文は、すべて利用者のローカル端末内でのみ処理されます。外部サーバーへの送信、テレメトリ収集、Web検索等は一切行いません。
- **公開リポジトリへの個人情報排除**: 本リポジトリのソースコード、コミット履歴、テスト用フィクスチャ、モックHTML、ドキュメント画像には、実在する個人情報（学籍番号、氏名等）や認証情報は一切含まれていません。
- **キャッシュのライフサイクル**: 読み込み中の一時キャッシュ（`_session_cache.jsonl`）は、CSV出力が正常完了した時点で自動的に削除されます。

脆弱性の報告やセキュリティ方針については [SECURITY.md](SECURITY.md) をご確認ください。
